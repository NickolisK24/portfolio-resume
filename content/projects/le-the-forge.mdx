## Problem

Last Epoch build optimization is genuinely hard: passives, skill trees,
idols, gear, affixes, ailments, conversions, and conditional modifiers all
interact in ways that most calculators flatten or ignore. I wanted The
Forge to model those systems deeply enough that the answers were
explainable, reproducible, and useful for real build decisions.

## Architecture

Six interconnected systems, each owning a clear slice of the calculation:

1. **Passive and skill tree engines** — model allocation rules, mastery
   gates, node effects, and build validation.
2. **Stat resolution pipeline** — aggregates gear, passives, idols,
   affixes, and conditional modifiers into a resolved stat state.
3. **Item and affix systems** — model equipment, implicits, affix pools,
   forging potential, and crafting behavior.
4. **Combat simulation** — runs deterministic damage and defensive
   calculations over realistic timelines.
5. **Crafting and optimizer foundations** — estimate crafting outcomes and
   explore build tradeoffs.
6. **Trusted data pipeline** — extracts and validates game data with
   reproducible reports and fail-closed checks.

## Key engineering decisions

- **Deterministic calculations first** — simulation outputs need to be
  reproducible before they are visually polished.
- **Shared stat pipeline** — passive trees, skill trees, items, and combat
  all resolve through common stat systems instead of duplicate logic.
- **Validation before expansion** — new systems include tests, debug
  visibility, and known limitation boundaries.
- **Trusted extracted data** — game data is treated as a source-of-truth
  pipeline with reports, provenance, and certification gates.

## Engineering Challenges

- Resolving thousands of interacting passive, item, skill, and ailment
  modifiers without double-counting.
- Building deterministic simulation pipelines that can be validated
  against in-game behavior.
- Maintaining trusted extracted game data while preserving reproducibility
  across patches.
- Keeping the architecture modular enough for future skills, items,
  crafting, and optimizer expansion.

## Status

Active development. Current focus is expanding trusted extracted game data,
simulation coverage, and build-planning capabilities while maintaining
deterministic and explainable calculations.
